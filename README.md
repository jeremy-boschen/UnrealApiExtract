# Unreal API Extractor

`UnrealApiExtractor <ModuleName>` builds a throwaway Unreal host project, enables the owning plugin (if needed), injects the module dependency, runs UHT-generating build steps, generates `compile_commands.json`, and emits LLM-friendly API artifacts.

## Features

- Module discovery from:
  - `Engine/Source`
  - `<Project>/Source`
  - `<Project>/Plugins/*/Source`
- `.Build.cs` parsing for module type + dependencies.
- Plugin auto-enable in cloned `.uproject` (no template mutation).
- Host module dependency injection (`Core`, `CoreUObject`, `Engine`, target module).
- Unity disable (`bUseUnity = false`) for cleaner extraction.
- Build + `GenerateClangDatabase` execution via UBT.
- Reflection extraction from source headers and UHT generated artifacts.
- Best-effort non-reflected AST symbol extraction from compile DB units.
- Optional symbol file ingestion (`--symbol-dump`) to pull API signatures/types from PDB-derived dumps.
- Output formats:
  - Canonical JSON API index
  - Human-readable summary TXT
  - SQLite index for retrieval
- Incremental cache keyed by engine version + dependency fingerprints.

## Install

```bash
python -m pip install -e .
```

## Usage

```bash
UnrealApiExtractor GameplayAbilities --config examples/config.example.toml --verbose

# Optional: include PDB symbol dump generated by llvm-pdbutil/dia2dump
UnrealApiExtractor GameplayAbilities --config examples/config.example.toml --symbol-dump C:/temp/GameplayAbilities.symbols.txt
```

## Config

See `examples/config.example.toml`.

## Output Layout

Outputs are written to:

```
<output_root>/<ModuleName>/
  api_index.json
  summary.txt
  api_index.sqlite
```

## Diagnostics

The CLI raises explicit errors for:
- Module not found
- Plugin enable failure
- Build failure
- UHT output missing
- compile_commands generation failure

## Notes

- Designed for Windows Unreal installs with command line only operation.
- Uses Python 3.11+.
- Excludes `Intermediate`, `Binaries`, `DerivedDataCache`, and `Saved` during source scans.
